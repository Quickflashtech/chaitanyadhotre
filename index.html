RogueAP Shield

.NET 9 · Windows Service · 2026

A Windows endpoint security tool that detects "evil twin" Wi-Fi attacks in real time. Combines seven independent detection signals — beacon frame hardware fingerprinting, gateway TTL anomalies, DNS resolution probing, and signal-strength baselining — into a single weighted risk score, so a rogue access point can't hide behind a spoofed SSID or MAC address alone. Backed by AES-256-GCM encrypted storage, a SHA-256 hash-chained tamper-evident audit log, and an automatic WireGuard kill switch enforced at the kernel level. Validated against a live evil-twin attack and a 53-access-point university campus environment.
